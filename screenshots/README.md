# Project Screenshots

This folder contains selected visualizations from the audio denoising experiments.

The screenshots provide a visual overview of the differences between the original, noisy, and denoised audio signals.

## 1. Waveform Comparison

### Audio 1

[`waveform_comparison_audio1.png`](./waveform_comparison_audio1.png)

This visualization compares the waveform of Audio 1 before and after noise reduction.

The comparison includes:

- Original audio
- Noisy audio
- Spectral Gating output
- Wiener Filter output

The waveform allows the amplitude characteristics of the signals to be visually compared.

### Audio 2

[`waveform_comparison_audio2.png`](./waveform_comparison_audio2.png)

This visualization shows the same waveform comparison for Audio 2.

## 2. Spectrogram Comparison

### Audio 1

[`spectrogram_comparison_audio1.png`](./spectrogram_comparison_audio1.png)

This visualization compares the frequency characteristics of Audio 1 using spectrograms.

The comparison includes:

- Original audio
- Noisy audio
- Spectral Gating output
- Wiener Filter output

The spectrogram provides a visual representation of how the frequency content changes before and after denoising.

### Audio 2

[`spectrogram_comparison_audio2.png`](./spectrogram_comparison_audio2.png)

This visualization presents the spectrogram comparison for Audio 2.

## 3. Evaluation Results

[`evaluation_results.png`](./evaluation_results.png)

This screenshot presents the quantitative evaluation results used to compare Spectral Gating and Wiener Filter.

The evaluation focuses on:

- Signal-to-Noise Ratio (SNR)
- Mean Squared Error (MSE)

The numerical evaluation is also available in:

[`Evaluasi_Denoising-2.xlsx`](../results/Evaluasi_Denoising-2.xlsx)

## Purpose of the Visualizations

The screenshots are included to provide a quick visual overview of the experimental results without requiring the reader to inspect the entire notebook.

The complete implementation and experimental workflow can be found in:

[`KODE_PSD_KEL_10.ipynb`](../notebooks/KODE_PSD_KEL_10.ipynb)
